# AgentPro - Agent Management System

## 📌 Project Overview

AgentPro is a web-based Agent Management System developed as part of the DataAlcott Web Development Internship.

The project helps manage agents, track their performance, calculate commissions, manage training, and view reports from one simple dashboard.

## 🎯 Objective

The main objective of this project is to create a simple and responsive system for managing agents and their activities.

## ✨ Features

- 📊 Dashboard with agent statistics
- 👤 Agent Registration
- 📋 Agent Listing
- 🔎 Agent Search
- 💰 Commission Management
- 📈 Performance Tracking
- 🎓 Training Management
- 🏆 Incentives and Rewards
- 📑 Reports
- 📱 Responsive Design
- 🚪 Logout Function
- ⚡ JavaScript Interactivity

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub
- GitHub Pages
